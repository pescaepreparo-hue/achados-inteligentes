# Achados Inteligentes — V9

Site estático de comparação e curadoria de produtos do Mercado Livre e da Shopee.

## Publicação na Netlify

1. Acesse https://app.netlify.com/start e entre ou crie conta gratuita.
2. Escolha **Import an existing project / Import from Git**.
3. Autorize o GitHub e escolha `pescaepreparo-hue/achados-inteligentes`.
4. Branch: `main`; base directory: deixe vazio; build command: deixe vazio; publish directory: `.`.
5. Clique em **Deploy / Publish** e verifique o endereço `*.netlify.app` oferecido pela Netlify.
6. Nas configurações, verifique que o site está **público** e que o plano está em **Free** antes de compartilhar links.

As próximas alterações enviadas para a branch `main` poderão ser publicadas automaticamente após vincular o repositório.

## Limites da versão atual

- O catálogo é **demonstrativo**; não são anúncios reais nem dados atualizados automaticamente.
- A Disputa 001 do Mini Power Bank contém dois links de afiliado informados anteriormente; confirme se ainda funcionam e se pertencem às contas corretas.
- Preços, frete, estoque, comissão e vencimento das ofertas **não** estão integrados em tempo real. O consumidor deve verificar na loja.
- A estrutura não possui back-end, autenticação, banco de dados ou API de marketplace. Não apresentar como comparador automático até implementar uma fonte autorizada de dados.
- Não publicar tarifas de comissão sem verificar os termos das plataformas.
